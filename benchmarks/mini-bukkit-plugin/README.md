# Mini Bukkit Plugin Benchmark

Petit projet de test pour OpticCode.

Objectifs :

- verifier l'inspection d'un projet Java 8 ;
- tester les prompts Bukkit/Spigot 1.8.8 ;
- tester la detection Maven ;
- garder un cas legacy avec `Material.SULPHUR` ;
- mesurer les temps de reponse sur un contexte petit mais realiste.

Contraintes :

- Java 8 ;
- Bukkit/Spigot 1.8.8 ;
- pas d'`api-version` dans `plugin.yml` ;
- dependency Spigot en `provided`.
